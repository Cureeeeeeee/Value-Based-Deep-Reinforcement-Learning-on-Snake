# ASSESSMENT 3 — official spec (verbatim copy from UTS Canvas page)

Purpose:	
To ensure that students have a clear understanding of the theoretical concepts, are able to implement/use them in a real-world problem context, and can independently / collaboratively design and implement solutions using Reinforcement Learning techniques.

Deliverables:	
 Multiple Deliverables:

Part A (5 pts): Project title, Abstract, Group details 
Part B (5 pts): Implementation/Development Plan
Part C (5 pts): Initial Experimental Results 
Part D (5 pts): Environment/GUI Design
Part E (40 pts): Final Project Report
Part F (15 pts): In-person presentation, Demo,
Part G (25 pts): Oral Defense

Important Note	
Please check individual submission pages for deadlines, respective deliverables, report templates, etc.  
Assignment-3 is incomplete without the presentation, demo, and viva/oral defense.
Marks for intermediate deliverables will be awarded only after the project has been completed in full. 
Final marks will be allocated proportionally based on each member’s individual contribution to the project, based on the agreed contribution in the final report.

Task
Potential/example problems or any combination (but not limited to):

Design/Implement/solve an image classification, object detection, etc. computer vision tasks using RL
Design/develop self-driving cars with AWS DeepRacer or similar
Design/develop a chess bot
Stock price prediction
Developing a custom OpenAI Gym environment (or something equivalent) and use RL methods to solve it, etc.
Students are encouraged to come-up with their own ideas/topic and discuss with the subject coordinator during the weekly consultation sessions to finalize. 

Student should develop an appropriate a user interface that allows/demonstrates the operational use of an algorithm to achieve a real-world solution. A list of potential project topic will be provided as a guide for discussion, but students are required to independently develop their project topics to have appropriate scope and focus.

For GUI:

Depending on the project topic, an exclusive interface (GUI) can be developed, appropriate to operationalize the RL solution.
For project using Open AI Gym environment, the built-in graphical environment can serve as the project's GUI, and as separate interface is not required. Same applies to 3rd-party or external environments where a graphical environment is available.
What kind of evidence is needed for this task?

Multiple deliverables as outlined above.
Google Colab (preferred) or IPython notebook, with the code or code repository. Code submission link will be provided by the subject coordinator after presentation and oral defense. 
It is expected the all team members must contribute equally in the project development and delivery.
Oral defense, presentation, recorded video. (please see individual submission page for details).
